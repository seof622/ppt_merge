# 앱 전용 글꼴

사용자가 다운로드한 Pretendard GOV 1.3.9 배포본의 `public/static`에서 가져온 원본 OTF 파일이다.

- `PretendardGOV-Medium.otf`: 본문·파일명·보조 안내, 굵기 500.
- `PretendardGOV-SemiBold.otf`: 제목·주요 버튼, 굵기 600.
- `PretendardGOV-Bold.otf`: 브랜드 등 굵기 700을 지정한 항목.
- `LICENSE.txt`: 배포본의 SIL Open Font License 1.1 원문.

원본 글꼴은 수정하지 않았다. Gruvbox EXE에 이 폴더를 포함하고 Qt의 앱 전용 글꼴 등록으로 읽는다. Windows 시스템 글꼴 폴더에는 설치하지 않는다.

프로젝트: https://github.com/orioncactus/pretendard

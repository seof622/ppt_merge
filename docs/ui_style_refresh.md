# UI 스타일 정리

2026-10-10, 버튼 스타일·색상과 글자 위계·간격 통일을 반영했다.

## 문구와 결과 파일 버튼 추가 정리

- 상단 버튼은 ‘폴더 선택’, 왼쪽 카드는 ‘PPT 선택’·‘PPT 목록’, 하단 제목은 ‘결과물 미리보기’로 변경했다.
- 파일·폴더 열기를 상태 표시줄에서 결과물 미리보기의 하단으로 옮겨 ‘파일 열기 · 폴더 열기 · PPT 생성’ 순서로 배치했다. 세 버튼은 모두 높이 36px이며, 열기 버튼에는 진한 파란 아이콘·텍스트와 연한 파란 배경·테두리를 적용했다.
- 생성한 결과 파일이 실제로 존재하고 읽기·생성·종료 작업 중이 아닐 때 열기 버튼을 표시한다. 새 생성에 실패해도 이전 성공 결과 파일이 남아 있으면 열기를 유지한다. 파일·폴더가 없어져 열기에 실패하면 UI 상태를 갱신해 버튼을 숨긴다.
- ‘PPT 선택’ 제목과 펼친 검색창을 함께 사용할 수 있도록 첫 카드의 최소 너비를 260px로 조정했다.

추가 변경은 `test_ux` 11개, `test_generation_ui` 7개, `test_file_browser` 32개의 모듈별 회귀 테스트로 검증했다. 별도 Qt 검증에서 생성 전·성공 결과 존재·파일 삭제 시 버튼 표시 조건, 세 버튼의 같은 높이·같은 줄 배치, 1600×900·1000×640의 텍스트 표시와 검색창 펼치기를 확인했다. 파일·폴더 열기 호출은 테스트에서 대체했다.

추가 화면은 `output/ui_labels_saved_1600.png`, `output/ui_labels_saved_1000.png`이며, 테스트 로그는 `output/ui_labels_test_*.log`, 빌드 로그는 `output/ui_labels_build.log`에 있다. 아래 검증은 처음 스타일 정리 단계의 기록이다.

- 상단·출력 편집 아이콘 버튼은 기본 테두리를 줄이고 hover·pressed·키보드 focus 상태로 구분한다. 검색이 열린 상태는 연한 파란 배경을 유지한다.
- 폴더·원본·출력 영역은 흰색, 슬라이드 작업 공간은 연한 회색으로 구분한다. 구분선과 카드 테두리는 옅게 표시하고 선택한 카드는 연한 파란 배경으로 강조한다.
- 출력 슬라이드가 있을 때 PPT 생성 버튼은 파란 배경·흰색 아이콘과 글자로 표시한다. 비활성 상태는 연한 회색으로 구분한다.
- 제목은 16px·600, 본문은 14px, 개수·경로·상태 보조 문구는 12px로 구분한다. 패널 여백은 16px, 내용 간격은 12px, 아이콘 버튼은 36×36px로 맞췄다. 폴더·원본·슬라이드 제목의 높이도 맞췄다.
- 스크롤바와 메뉴에도 같은 색상·간격 기준을 적용했다. 작은 창에서는 원본 슬라이드 카드를 196×126px, 아이콘을 160×80px, 카드 간격을 4px로 조정해 카드와 번호가 잘리지 않게 했다.

## 검증

관련 테스트를 모듈별 별도 Python 프로세스에서 실행해 총 62개가 통과했다.

| 모듈 | 결과 |
|---|---|
| test_ui | 9개 통과 |
| test_file_browser | 32개 통과 |
| test_output_ui | 10개 통과 |
| test_ux | 11개 통과 |

실제 Qt 이벤트 루프에서 1600×900·1000×640의 슬라이드·출력 목록 표시, 빈 화면, 생성 버튼의 활성·비활성 상태, 제목 높이, 검색창의 남은 너비 채우기, 작은 창의 카드 표시 범위를 확인했다. 화면 검증은 기존 캐시 이미지와 테스트용 원본·가짜 읽기 서비스로 수행했고, 이번 변경에서 실제 PowerPoint 결합 엔진 통합 검증은 재실행하지 않았다.

네 모듈을 한 Python 프로세스에서 함께 실행하면 검색 종료 테스트 중 Python GC 시점에 Qt가 abort하는 기존 문제가 재현된다. 변경 전 커밋 `89c7b8c`의 별도 체크아웃에서도 같은 현상을 확인했다. 따라서 이번 테스트 결과는 모듈별 실행 범위이며 전체 조합 실행의 성공을 의미하지 않는다. 해당 로그는 `output/ui_refresh_unit.log`, `output/ui_refresh_baseline_unit.log`에 있다.

## 산출물

- 최종 실행 파일: `dist/PPTMerge.exe`
- 슬라이드·출력 목록 화면: `output/ui_refresh_loaded_1600.png`, `output/ui_refresh_loaded_1000.png`
- 빈 화면: `output/ui_refresh_empty_1000.png`
- 테스트 로그: `output/ui_refresh_test_*.log`
- 빌드 로그: `output/ui_refresh_build.log`

```powershell
$env:PYTHONPATH = "$PWD\tests\unit"
foreach ($suite in 'test_ui', 'test_file_browser', 'test_output_ui', 'test_ux') {
    .\.venv\Scripts\python.exe -X utf8 -m unittest $suite
    if ($LASTEXITCODE -ne 0) { throw "실패: $suite" }
}
```

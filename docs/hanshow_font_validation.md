# 사용자 원본과 한쇼 글꼴 표시 확인

2026-10-11, `temp`의 PPTX 2개와 사용자가 16:22에 만든 바탕 화면 `result.pptx`를 한쇼 2022에서 읽기 전용으로 열어 비교했다. 해당 결과의 순서는 113번 2장, 17번 3장이다.

- 한쇼에서 원본과 결과를 각각 1280×960 PNG로 내보냈을 때 5장 모두 픽셀이 일치했다. 앞서 제공한 `merged_polaris_verified.pptx`도 해당 파일 순서에 맞춰 비교한 5장 모두 일치했다.
- 원본 제목의 글꼴 지정은 `THE외계인설명서`와 `HY얕은샘물M`이다. 병합 결과의 실제 텍스트 run에도 같은 글꼴 지정이 남아 있다.
- 원본 두 파일과 병합 결과에는 `ppt/fonts/`의 포함 글꼴 파일이 없다.
- Windows에서 열거한 글꼴 목록(QFontDatabase)에 두 글꼴이 없다. 시스템 글꼴 등록에서도 관련 글꼴 이름을 찾지 못했다. 글꼴 이름이 문서에 남는 것만으로 해당 글꼴 파일을 사용할 수 있는 것은 아니다.
- 한쇼 편집 화면에서 실제 바탕 화면 `result.pptx`를 열고 첫 장 제목을 선택해 `HY얕은샘물M`, 45pt 지정을 확인했다. 글자 모양이 달라 보이는 상태는 원본을 열었을 때도 같다.

위 비교는 한쇼 안에서 원본과 병합 결과가 같은지를 확인한 것이다. 앱 간 글꼴 표시가 같다는 의미는 아니다. 원래 글꼴 모양을 복원하려면 해당 글꼴을 사용할 수 있는 환경이 필요하다. 글꼴을 바꾸는 작업은 원본 보존과 다른 편집이므로 이 확인에서는 수행하지 않았다.

## 같은 결과의 3페이지를 한쇼와 Polaris에서 비교

사용자가 지적한 제목 `주가 보이신 생명의 길`을 두 앱의 실제 편집 화면에서 다시 확인했다. 대상은 같은 바탕 화면 `result.pptx`이며, 두 앱 모두 3/5 페이지를 표시한 상태였다.

- Polaris Office에서는 제목이 굵고 둥근 글자 모양으로 표시된다.
- 한쇼 2022에서는 제목이 다른 고딕체 모양으로 표시된다. 제목을 선택하면 글꼴 선택 상자에 원본의 `THE외계인설명서` 지정과 노란 경고 아이콘이 보이고 크기는 36pt이다.
- 표시 배율은 달랐지만, 글자 획과 모서리 모양이 다르므로 배율만의 차이가 아니다. 각 앱이 실제로 사용한 대체 글꼴의 이름은 확인하지 않았다.

따라서 앱 간 제목 글꼴 표시 차이는 재현됐다. 원본과 결과의 글꼴 지정은 같고, 해당 시스템 글꼴과 파일 내 포함 글꼴이 없는 점을 함께 고려하면 앱별 글꼴 대체 또는 글꼴 제공 방식의 차이로 판단한다. 이는 추론이며 Polaris가 원본 글꼴을 제공하는지까지 확인한 것은 아니다. 기존 한쇼 내부 픽셀 비교만으로 앱 간 호환성이 해결됐다고 결론 내릴 수 없다. 이번 확인에서 사용자 PPT나 병합 코드를 변경하지 않았다.

최근 결과 비교 보고서: `output/hanshow_fonts_vt3vr96t/report.json`. 한쇼 COM의 일부 Font 속성 조회는 예외를 반환해 글꼴 판정에 사용하지 않았다. 실제 패키지의 텍스트 글꼴 지정, 설치 목록, 한쇼 UI와 렌더링을 근거로 확인했다. 확인용 COM 세션의 한쇼 프로세스는 정상 종료했고, 사용자의 현재 결과는 한쇼 편집 화면에 열어두었다.

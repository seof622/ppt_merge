# 기본 PowerPoint COM PoC 검증

기본 테스트 자료의 결합 및 자동 비교를 완료했고, 사용자가 외관·슬라이드 쇼·편집 동작을 확인한 뒤 ‘이상 없음’으로 응답했습니다. 기본 PoC의 자동·수동 검증 모두 통과했습니다. 아래 확인 절차는 재검증할 때 사용할 수 있습니다.

## 열어 볼 파일

- [원본 A.pptx](../tests/fixtures/basic/A.pptx): 파란색 테마, 4장
- [원본 B.pptx](../tests/fixtures/basic/B.pptx): 초록색 테마, 4장
- [기본 결합 결과, 3장](../output/poc_20261007_153626/demo_insert_file_design.pptx)
- [전체 및 중복 결합 결과, 9장](../output/poc_20261007_153626/coverage_insert_file_design.pptx)
- [자동 비교 보고서](../output/poc_20261007_153626/report.json)
- [PPTX 무결성과 이미지·차트·내장 Excel 비교 보고서](../output/poc_20261007_153626/package_audit.json)

결과 파일은 로컬 `output/`에 있어 Git에서 제외됩니다. 이 안내의 링크는 현재 실행 결과를 가리킵니다. 재실행하면 새 폴더에 결과가 생성됩니다.

## 사용자가 확인할 사항

1. **복구 경고 없이 열리는지 확인합니다.** 원본 A, B와 3장 결과를 PowerPoint에서 엽니다. 결과 1장은 A의 2장, 결과 2장은 B의 4장, 결과 3장은 A의 1장과 비교합니다.
2. **외관을 비교합니다.** 글자·이미지·그룹 도형·표 위치가 같은지, A의 파란색과 B의 초록색 강조색·배경·하단 마스터 띠가 유지되는지 확인합니다.
3. **슬라이드 쇼를 실행합니다.** 3장 결과에서 `F5`를 누릅니다. 첫 슬라이드의 그룹 도형과 두 번째 슬라이드의 강조색 사각형은 클릭할 때 페이드로 나타나야 합니다. 다음 장으로 넘어갈 때 페이드 전환도 원본과 비교합니다.
4. **발표자 노트와 편집 동작을 확인합니다.** 결과의 노트는 순서대로 `NOTES_A-2`, `NOTES_B-4`, `NOTES_A-1`이어야 합니다. 9장 결과의 2·6·9장에서 표의 셀을 선택할 수 있어야 하고, 3·7장에서 차트 우클릭 후 ‘데이터 편집’으로 `10, 20, 15` 값을 볼 수 있어야 합니다. 확인 중 바꾼 내용은 저장하지 않아도 됩니다.
5. **순서와 중복을 확인합니다.** 9장 결과는 `A-1, A-2, A-3, A-4, B-1, B-2, B-3, B-4, A-2`입니다. 마지막 A-2가 두 번째 A-2와 같아야 합니다.

재검증 후에는 ‘이상 없음’ 또는 ‘파일명 / 결과 슬라이드 번호 / 원본과 다른 점’을 기록합니다. 예: `3장 결과 / 2번 / 클릭해도 사각형이 나타나지 않음`. 현재 기본 자료의 수동 검증 결과는 **통과**입니다.

## 자동 검증 결과

실행 환경은 Windows의 PowerPoint 16.0, Python 3.12.14, pywin32 312, Pillow 12.3.0입니다.

| 결합 방식 | 3장 순서 | 9장 전체·중복 | 원본 외관 |
| --- | --- | --- | --- |
| `Slide.Copy()` + `Slides.Paste()` | 결합됨 | 결합됨 | 배경·테마·레이아웃과 테마 도형 색상에 차이 발견 |
| `Slides.InsertFromFile()` | 결합됨 | 결합됨 | 배경·테마·레이아웃과 테마 도형 색상에 차이 발견 |
| `InsertFromFile` + `Designs.Clone` + 원본 디자인·레이아웃 적용 | 통과 | 통과 | 비교한 12장 모두 일치 |

후속 결합 엔진 후보는 세 번째 방식입니다. 슬라이드와 디자인을 PowerPoint COM으로 복사하고 원본 레이아웃을 연결합니다. 슬라이드 콘텐츠를 요소별로 재구성하지 않습니다.

통과한 방식에서 확인한 항목:

- 출력 슬라이드 수와 순서, 동일 소스 슬라이드 중복
- 모든 도형 및 그룹 자식의 타입·위치·크기·회전·텍스트·글꼴·굵기·색상, 표 셀 내용, 차트 타입
- 발표자 노트, 기본 페이드 애니메이션 타입·대상·트리거·지속 시간, 전환 효과
- 테마 색상, 배경색, 레이아웃 이름, 외부 하이퍼링크 주소
- PowerPoint가 내보낸 1280×720 PNG의 픽셀 완전 일치
- 삽입 이미지 원본 바이트, 차트 캐시 값·텍스트, 내장 Excel 통합문서 바이트의 일치
- PPTX ZIP 무결성 및 내부 관계의 대상 파일 존재

PowerPoint는 새 프레젠테이션에서 내부 `Slide.Name`을 재할당합니다. 원본 이름과 출력 이름은 보고서에 기록하되 보존 실패로 판정하지 않습니다. 순서는 실제 제목을 포함한 전체 슬라이드 내용으로 검증합니다. 내부 슬라이드 링크의 보존·재연결은 [고급 검증](advanced_validation.md)에서 확인했습니다.

| 신뢰성 사례 | 결과 |
| --- | --- |
| 10개 소스 파일을 열고 종료 | 통과, 앱 소유 PowerPoint 종료 |
| 1장 결합 후 안전 지점에서 취소 | 통과, 문서·참조 정리 및 부분 결과 미공개 |
| 생성 중 의도적으로 예외 발생 | 통과, 문서·참조 정리 및 부분 결과 미공개 |
| 없는 소스 파일 오류 후 정상 소스로 생성 | 통과, 다른 소스 사용 가능 |
| 16:9와 4:3 소스 혼합 | 통과, 생성 전 크기 불일치 감지 및 중단 |
| 기존 PowerPoint 세션이 열린 상태 | 통과, PoC 접근 거부 및 기존 세션 유지 |

현재 PoC는 기존 PowerPoint가 열려 있으면 실행을 거부합니다. 기존 사용자 세션과 동시에 동작하는 지원은 후속 과제입니다. 취소 검증은 슬라이드 사이의 안전한 지점에서 수행했으며, 저장 도중의 강제 중단은 포함하지 않습니다.

기본 자료에는 SVG, SmartArt, 외부 Excel 연결 OLE 차트, 일반 OLE 객체, 오디오·비디오, 내부 슬라이드 링크, `.pptm`, 모션 애니메이션이 없습니다. 이 항목은 [고급 검증 안내](advanced_validation.md)에 자동 검증 결과와 수동 확인 절차를 기록했습니다. 실제 VBA 매크로가 있는 파일, 암호화·손상 파일은 미검증입니다.

2026-10-07 고급 검증 코드 추가 후 기본 테스트를 재실행했습니다. 선택한 디자인 보존 방식의 12장 비교와 신뢰성 6개 사례가 다시 통과했습니다. 최신 자동 보고서는 [output/poc_20261007_162234/report.json](../output/poc_20261007_162234/report.json)입니다. 다른 두 방식의 테마 차이는 기존 결과와 같습니다.

## 실행 및 코드

```powershell
.\.venv\Scripts\python.exe scripts/poc/run_poc.py
```

PowerPoint를 닫은 상태에서 실행합니다. 새 환경에서는 먼저 `requirements-poc.txt`를 설치합니다. 실행 로그는 `logs/poc.log`, 결과와 비교 PNG는 매번 생성하는 `output/poc_<날짜_시간>/`에 저장합니다.

- `scripts/poc/create_fixtures.py`: 기본 PPT 생성, 기존 자료 덮어쓰기 방지
- `scripts/poc/com_session.py`: COM 초기화·해제, 소유 세션 관리, 정상 종료
- `scripts/poc/run_poc.py`: 결합 방식 비교, 원본 디자인 적용, 취소·오류·크기·세션 보호 검증
- `scripts/poc/verify_slides.py`: COM 메타데이터·PPTX 내부 자료·PNG 비교

API 동작은 Microsoft의 [Slides.Paste](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slides.paste), [Slides.InsertFromFile](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slides.insertfromfile), [Designs.Clone](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.designs.clone) 문서를 참고했습니다. 위 보존 결과는 이 컴퓨터의 실제 테스트 결과입니다.

# 슬라이드 구성 중심 UI

2026-11-16, 자료 선택과 결과 편집을 중심으로 화면을 재구성했다.

## 사용 흐름

- `PPT 추가` 또는 Ctrl+O로 여러 PPTX·PPTM을 선택한다. 외부 파일 끌어 놓기도 지원한다.
- 자료 사이드바의 `불러온 PPT`와 `폴더 탐색` 탭을 전환한다. 폴더 지정은 Ctrl+Shift+O, 폴더 안의 파일명 검색은 Ctrl+F이다.
- 원본 영역에서 현재 PPT의 슬라이드 제목·본문을 검색한다. 본문 검색은 PPTX에 저장된 텍스트를 대상으로 하며 이미지 속 글자 OCR은 포함하지 않는다. 파일 읽기는 기존 워커에서 처리한다.
- 선택한 장 또는 표시된 슬라이드 전체를 결과에 담는다. 기존 더블클릭 담기·Ctrl/Shift 선택·드래그도 유지한다.
- 결과는 기본 격자로 표시한다. 가로 목록, 썸네일 크기 조절, 드래그 순서 변경, 삭제·복제·이동을 지원한다. 원본에는 결과에 사용한 횟수를 표시한다.
- `확대 보기` 또는 Space로 선택한 슬라이드의 캐시 이미지를 확대한다. 확대 창의 이전·다음 버튼과 방향키로 이동한다. 캐시 해상도를 확대하므로 원본 PPT를 직접 여는 것과 같은 선명도를 보장하지는 않는다.
- Ctrl+Z로 편집을 취소하고 Ctrl+Y 또는 Ctrl+Shift+Z로 다시 실행한다. 추가·삭제·복제·순서 변경·전체 비우기를 최대 100개 작업까지 복구한다.
- `PPT로 저장` 또는 Ctrl+S로 결과를 생성한다. 완료 후 파일·폴더 열기 버튼을 표시한다.

1320px 이상에서는 원본과 결과를 나란히 보여 준다. 좁은 창에서는 `원본 보기`와 `결과 편집`으로 전환하며 자료 목록과 저장 버튼은 유지한다. 넓은 창에서도 결과만 크게 볼 수 있다. 최소 창 크기는 1000×640이다.

## 작업 자동 복원

350ms 지연 저장과 정상 종료 시 저장으로 `workspace.json`에 자료 경로와 결과 순서를 보관한다. EXE는 `%LOCALAPPDATA%/PPTMerge`, 소스 실행은 프로젝트 루트에 저장한다. QSaveFile로 원자적으로 교체한다. 원본 PPT는 변경하지 않는다.

다시 실행하면 원본을 기존 워커로 읽고 슬라이드 ID·번호·원본 리비전이 일치하는 결과 항목만 복원한다. 다른 원본과 중복 슬라이드의 순서도 유지한다. 파일이 없거나 변경·읽기 실패가 발생하면 제외한 항목 수를 안내한다. 일부만 복원된 경우 사용자가 새로 편집하기 전까지 이전 작업 기록을 덮어쓰지 않는다. 실행 취소 기록은 세션 간 복원하지 않는다.

## 검증

기존 병합·취소·파일 보호 검사에 새 편집·화면 전환·검색·복원 검사를 추가했다. Qt offscreen 환경에서 실제 위젯·선택·키보드·드롭 이벤트로 검증하며 PowerPoint COM을 호출하는 실제 Office 통합 검증과는 구분한다.

최종 단위·Qt UI 테스트 162개가 54.313초에 통과했다. 로그는 `output/modern_workspace_tests.log`이다. `git diff --check`를 통과했다. EXE 재빌드는 성공했고, 배포 번들 내부에서 새 카드·확대 보기·본문 검색·작업 저장 모듈의 포함을 확인했다. 이번 변경에서 실제 Office COM 병합과 스마트 앱 컨트롤 아래의 EXE 실행은 재검증하지 않았다.

화면 검토 자료:

- `output/modern_workspace_1600.png`
- `output/modern_workspace_1000_source.png`
- `output/modern_workspace_1000_result.png`
- `output/modern_workspace_empty.png`

실행 파일은 `dist/PPTMerge.exe`로 갱신한다. 이 UI 변경은 Windows 코드 서명을 추가하지 않으므로 기존 스마트 앱 컨트롤 차단 문제와 별개다. 개발 PC에서는 `run_app.bat`으로 실행할 수 있다.
